# Event Decor Website with Admin Panel

Сайт-портфолио для студии event декора с админ-панелью и формой заявок.

## Структура проекта

```
сайт/
├── app.py                 # Основное приложение Flask
├── requirements.txt       # Зависимости Python
├── README.md             # Эта инструкция
├── templates/            # HTML шаблоны
│   ├── base.html         # Базовый шаблон сайта
│   ├── index.html        # Главная страница
│   ├── portfolio.html    # Страница портфолио
│   ├── contact.html      # Страница контактов
│   └── admin/            # Шаблоны админ-панели
│       ├── base.html
│       ├── login.html
│       ├── dashboard.html
│       ├── orders.html
│       ├── order_detail.html
│       ├── portfolio.html
│       └── portfolio_form.html
└── static/               # Статические файлы
    ├── css/
    │   ├── style.css     # Стили сайта
    │   └── admin.css     # Стили админ-панели
    └── js/
        ├── main.js       # Скрипты сайта
        └── admin.js      # Скрипты админ-панели
```

## Установка

### 1. Установите Python

Если у вас не установлен Python, скачайте и установите его с официального сайта: https://www.python.org/downloads/

### 2. Установите зависимости

Откройте терминал (командную строку) в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

### 3. Настройте email (опционально)

Откройте файл `app.py` и измените следующие строки с вашими данными:

```python
app.config['MAIL_USERNAME'] = 'your-email@gmail.com'  # Ваш email
app.config['MAIL_PASSWORD'] = 'your-app-password'      # Пароль приложения
```

**Важно:** Для Gmail нужно создать "App Password":
1. Зайдите в настройки Google Аккаунта
2. Выберите "Безопасность"
3. Включите двухфакторную аутентификацию (если не включена)
4. Создайте "Пароль приложения"
5. Используйте этот пароль вместо обычного

### 4. Запустите приложение

```bash
python app.py
```

Приложение запустится и автоматически создаст базу данных с администратором по умолчанию.

## Функционал

### Для посетителей сайта:
- Просмотр главной страницы с услугами
- Просмотр портфолио с фильтрацией по категориям
- Отправка заявки через форму
- Заявка отправляется на email владельца

### Для администратора:
- **Дашборд** - статистика и последние заявки
- **Заявки** - просмотр всех заявок, фильтрация по статусу
- **Детали заявки** - полная информация, изменение статуса, удаление
- **Портфолио** - добавление, редактирование, удаление работ

### Статусы заявок:
- 🆕 Новая (new)
- ⏳ В работе (in_progress)
- ✅ Завершена (completed)
- ❌ Отменена (cancelled)

## База данных

База данных SQLite автоматически создается в файле `instance/event_decor.db`.

### Сброс базы данных
Если нужно начать заново, удалите файл базы данных и перезапустите приложение:

```bash
# Windows (PowerShell)
Remove-Item -Path instance\event_decor.db -Recurse -Force

# Windows (cmd)
rmdir /s /q instance

# Затем перезапустите приложение
python app.py
```

## Добавление тестовых данных

Вы можете добавить тестовые данные через админ-панель:
1. Войдите как admin
2. Перейдите в раздел "Портфолио"
3. Нажмите "Добавить работу"
4. Заполните форму (для изображения можно использовать URL с любого сайта)

## Безопасность

⚠️ **Важно!** Перед запуском на production:

1. Измените `SECRET_KEY` в `app.py` на случайную строку
2. Измените пароль администратора (или создайте нового с хешированным паролем)
3. Настройте email для получения заявок
4. Используйте HTTPS на production

## Решение проблем

### Ошибка "ModuleNotFoundError"
Убедитесь, что все зависимости установлены:
```bash
pip install -r requirements.txt
```

### Ошибка при отправке email
Проверьте настройки email в `app.py`:
- Правильность email адреса
- Пароль приложения (не обычный пароль от Gmail)
- Разрешение на доступ менее защищенных приложений

### Порт 5000 уже занят
Измените порт в конце `app.py`:
```python
app.run(debug=True, port=5001)  # Используйте другой порт
```
