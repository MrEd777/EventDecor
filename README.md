# Event Decor - Сайт агентства событийного декора

## Структура проекта

```
.
├── app.py                  # Основной файл приложения (Flask + SQLAlchemy)
├── requirements.txt        # Список зависимостей Python
├── instance/
│   └── event_decor.db      # База данных SQLite
├── static/
│   ├── css/
│   │   └── style.css       # Основной файл стилей (единый для всего сайта)
│   ├── img/                # Статические изображения и иконки
│   ├── js/                 # JavaScript скрипты
│   └── uploads/            # Загруженные фотографии работ и категорий
└── templates/
    ├── base.html           # Базовый шаблон (хедер, футер, модальное окно заказа)
    ├── index.html          # Главная страница с услугами и формой
    ├── events.html         # Список работ в категории (плитка)
    ├── event_detail.html   # Детальный просмотр работы (галерея)
    └── admin/              # Шаблоны панели управления
        ├── base.html       # Базовый шаблон админки
        ├── dashboard.html  # Дашборд со статистикой и новыми заявками
        ├── login.html      # Страница входа администратора
        ├── orders.html     # Список всех входящих заявок
        ├── order_detail.html # Просмотр и изменение статуса заявки
        ├── portfolio.html  # Список работ в админке
        ├── portfolio_form.html # Форма добавления и редактирования работы
        ├── portfolio_photos.html # Управление дополнительными фото в галерее
        ├── pricing.html    # Управление списком услуг и ценами
        └── settings.html   # Настройки профиля администратора
```
